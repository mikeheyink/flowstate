# Available Skills

This project is equipped with specialized AI Agent Skills to handle different aspects of the software development lifecycle. You can invoke these skills by name or context.

## 1. Product Manager
*   **Trigger:** "Act as PM", "Spec this out", "Write user stories"
*   **Role:** Refines requirements, writes PRDs, prioritizes features, and ensures user value.
*   **Path:** `.agent/skills/product-manager/SKILL.md`

## 2. Systems Architect
*   **Trigger:** "Design the system", "Create tech spec", "Data modeling"
*   **Role:** Translates PRDs into technical specifications, database schemas, and API designs.
*   **Path:** `.agent/skills/systems-architect/SKILL.md`

## 3. Frontend Architect
*   **Trigger:** "Review code", "Refactor", "Optimize performance"
*   **Role:** Focuses on code quality, React/TypeScript best practices, Zustand state management, and performance.
*   **Path:** `.agent/skills/frontend-architect/SKILL.md`

## 4. UX Designer
*   **Trigger:** "Improve UI", "Make it look premium", "Add animations"
*   **Role:** Focuses on aesthetics, "Linear-style" design, motion, and CSS variables.
*   **Path:** `.agent/skills/ux-designer/SKILL.md`
